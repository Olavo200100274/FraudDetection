\section{FT-Transformer Attention Diagnostics --- Individual Case Bar Charts}
\label{appendixB}
% ══════════════════════════════════════════════════════════════════════════

The following figures supplement Section~\ref{sec:attention_diagnostics} of the Results chapter. Each bar chart shows the per-feature attention weight for a single test case, with categorical features in orange and numerical features in blue. The dashed horizontal line marks the uniform attention baseline ($1/31 \approx 3.2\%$). All six cases are borderline: their predicted fraud scores lie within $0.001$ of the decision threshold ($\tau = 0.058$), making them the most ambiguous predictions in the test set.

Even at this individual, maximally uncertain level, no feature receives substantially elevated attention relative to the uniform baseline. This confirms that the Foggy Vision pattern observed in the aggregate (Figure~\ref{fig:attention_aggregate}) is not an averaging artefact but a genuine property of how the FT-Transformer processes these inputs.
